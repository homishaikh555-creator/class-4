CSS Box Model

Content, Padding, Border and Margin

What is the Box Model?

Every HTML element is a rectangular box made up of content, padding, border and margin. The examples below show how changing padding, border, width and height affects the size of a box.

1. Different Width Values

Boxes A and B use a 200px content width. Box C uses a 200px total width with border-box.

Box A

Content width: 200px

Padding: 10px

Border: 2px

Box B

Content width: 200px

Padding: 25px

Border: 5px

Box C

Total width: 200px

Padding: 25px

Border: 5px

border-box

2. Different Height Values

Boxes A and B use a 100px content height. Box C uses a total height of 160px with border-box.

Content height: 100px

Padding: 10px

Height B

Padding: 25px

3. Four Parts of the Box Model

CONTENT

Outer area = Margin | Orange = Border | Yellow = Padding | Green = Content

Conclusion

content-box: The declared width and height apply to the content only. Padding and border are added outside those dimensions.

border-box: The declared width and height include the content, padding and border. This makes element sizing easier to control.
